    Perangkat

    Pengaturan Relay

    Kalau saat diuji lampu dan peltier terbalik, atau relay menyala saat seharusnya mati, perbaiki di sini tanpa bongkar kabel. Disimpan permanen di memori ESP32.

    Setelah disimpan semua relay mati sebentar (jeda aman 10 detik). Uji dengan mode MANUAL di menu Kontrol.

    WiFi Tersimpan

      Maksimal 5 WiFi, tersimpan di memori ESP32. Urutan = prioritas: WiFi nomor 1 adalah utama, jika tidak ada perangkat langsung mencoba WiFi berikutnya. Jika tidak ada WiFi sama sekali selama 60 detik, perangkat membuat hotspot terbuka MANGGOT-SETUP (buka 192.168.4.1).

      Reboot Otomatis

      Update Firmware

      Cara lain: dari GitHub (publish.bat) / URL

      File .bin didapat dari Arduino IDE › Sketch › Export Compiled Binary (pakai file .ino.bin, bukan bootloader/merged). Partition Scheme ESP32 harus Minimal SPIFFS.
